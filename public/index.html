自訂問卷題目

第 1 題固定由系統依據玩家版本動態引導；下方題目為第 2 題開始之問卷內容，可自由增減修改。

STEP 1 前置環境需求準備

部署本系統前請確認已具備以下前置項目：

  1. Node.js：版本需求 v18.x 或 v20.x+。
  2. MCSManager 面板：v9 / v10，並已在「使用者管理」生成 API Key。
  3. Minecraft 伺服器核心支援：
    • 純基岩版服 (BDS)：原裝 Bedrock Dedicated Server、Nukkit 或 PocketMine。
    • 純 Java 服：Vanilla、Paper、Purpur、Fabric 或 Forge。
    • 雙端互通服：Paper / Fabric 搭配安裝 Geyser 與 Floodgate。
STEP 2 Discord 機器人建立與特權意圖

前往 Discord Developer Portal 建立 Application 並進入 Bot 標籤頁：

  1. 開啟特權意圖 (Privileged Gateway Intents)：請將 PRESENCE INTENT、SERVER MEMBERS INTENT、MESSAGE CONTENT INTENT 全部勾選開啟。
  2. 邀請機器人：OAuth2 範圍勾選 bot，權限給予 Administrator 或管理頻道/身分組/暱稱等權限。
  3. 身分組順序：在 Discord 伺服器身分組清單中，務必將機器人的身分組拖曳至「已驗證」身分組之上。
STEP 3 Google Apps Script (GAS) 試算表部署

將玩家作答與審核狀態即時非同步同步至 Google 試算表：

  1. 建立一份新的 Google 試算表，點選頂部選單 擴充功能 > Apps Script。
  2. 將專案中的 Code.gs 原始碼貼入編輯器並儲存。
  3. 點擊右上角 部署 > 新增部署作業。
  4. 類型選擇 網頁應用程式 (Web App)，存取權限設為 所有人 (Anyone)。
  5. 複製產生的網頁應用程式網址，填入「API 金鑰與環境變數」中的 GAS_WEBHOOK_URL 欄位。
STEP 4 MCSManager 面板 API 串接

讓機器人能遠端發送指令寫入伺服器白名單：

  1. 取得 API Key：登入 MCSManager 面板，前往 使用者管理 複製管理員 API Key。
  2. 取得實例 UUID 與 Daemon ID：進入伺服器實例終端介面，在網址列或設定中找到 uuid 與 daemonId。
  3. 填入設定後台：將面板網址與 API Key 寫入「API 金鑰與環境變數」，並在「伺服器與節點設定」中直接輸入實例 UUID 與節點 ID。
STEP 5 跨平台與版本分流運作機制

系統如何處理 Java 與基岩版玩家：

  • 雙端互通模式：申請時機器人自動提供 Java 與基岩版選擇按鈕，玩家輸入原始 ID 即可，系統後端自動處理前綴補綴與指令派發。
  • 多節點精準路由：審核通過時，Java 玩家僅寫入設定為 ALL 與 JAVA_ONLY 的實例；基岩版玩家僅寫入 ALL 與 BEDROCK_ONLY 的實例。
